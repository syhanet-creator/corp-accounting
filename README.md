# 법인회계프로그램 (무료버전 1.13)

기업회계기준(중소기업 회계기준)을 적용한 오프라인 우선(offline-first) 복식부기 회계 웹 애플리케이션입니다. 별도의 서버나 데이터베이스 없이, 브라우저 안에서 모든 계산과 저장이 이루어집니다.

## 주요 기능

- **재무회계**: 전표(회계결의서) 작성, 원장/시산표, 재무상태표·손익계산서, 연도결산/이월
- **세무회계**: 세금코드(부가세 매입/매출, 원천징수) 기반 자동 분개, 부가세·원천세 신고/납부 정리, XML 전자세금계산서 업로드·검증
- **재고/원가관리**: 품목별 입출고, 선입선출법/이동평균법/개별법 원가계산, 재고수불부, 재고실사·조정
- **자금·예산·관리회계**: 자금현황/자금계획, 채권채무 현황(선입선출 매칭), 계정별 예산 대비 실적, 부서·프로젝트별 손익분석, 손익분기점 계산기
- **내부통제**: 담당자 로그인(아이디/비밀번호), 전표 작성자·결재자 지정, 결재(승인/반려) 워크플로
- **유형자산/계약 관리**: 비품 취득·감가상각 자동 계산, 계약별 집행률 관리
- **화면 배율 조절**: Ctrl+마우스 휠로 화면을 확대/축소(작은 화면에서 유용)

## 실행 방법

### 온라인 (권장)

Vercel로 배포된 주소에 접속해 바로 사용하면 됩니다.

### 로컬 실행

`index.html` 파일을 더블클릭해서 열거나, 정적 서버로 띄워도 됩니다.

```bash
npx serve .
```

## 데이터는 어디에 저장되나요?

이 프로그램은 서버가 없습니다. 입력한 모든 회계 자료는 **지금 사용 중인 브라우저(기기)에만** 저장됩니다.

- 같은 PC, 같은 브라우저로 다시 접속하면 마지막 작업 내용이 그대로 이어집니다.
- 브라우저 저장공간을 지우거나, 다른 PC·다른 브라우저로 접속하면 자료가 보이지 않습니다. [설정/백업] 화면에서 주기적으로 자료를 파일로 저장해 두는 것을 권장합니다.
- 여러 사람이 같은 배포 주소에 접속해도 서로의 자료는 공유되지 않고 각자의 브라우저에만 따로 저장됩니다.

## 담당자 로그인/결재 기능에 대한 안내

[설정/백업]에서 담당자별 아이디·비밀번호를 설정하면, 전표에 결재자를 지정해 승인/반려 워크플로를 쓸 수 있습니다. 비밀번호는 평문이 아니라 무작위 salt + SHA-256 해시로 저장되지만, **이 기능은 서버 인증이 아니라 "누가 처리했는지" 확인하는 내부통제용 신원 확인**입니다. 브라우저 저장공간에 직접 접근하면 우회될 수 있는 수준이라는 점을 참고해 주세요.

## 배포 (Vercel)

이 저장소는 빌드 과정이 필요 없는 정적 사이트입니다. Vercel에서 "New Project → 이 GitHub 저장소 선택 → Deploy"만 누르면 별도 설정 없이 배포됩니다(Framework Preset: Other/정적 사이트로 자동 인식).

## PDF 첨부/인쇄 관련 안내

증빙 PDF 첨부, 파일 열기/인쇄 연동 기능은 **로컬 실행 파일(EXE) 버전에서만 동작**합니다. 웹(Vercel)으로 열었을 때는 이 기능을 쓰려고 하면 EXE 버전 안내 메시지가 뜨며, 그 외 회계 처리 기능은 모두 동일하게 사용할 수 있습니다.
